# Reglamento Interno index

**Status:** DRAFT, not yet reviewed

Finds the articles that concern assemblies and voting. It paraphrases them and carries no authority, so check the Reglamento before citing one.

**Edition:** June 2022 copy. The current edition is unconfirmed.

The Tool column is provisional until the system boundary is decided. "Input" means people decide and the tool receives the result.
