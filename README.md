# Sistema de votaciones ASDMR

Aplicación web para apoyar las votaciones secretas de una Asamblea presencial de la Unión Hondureña. V1 ofrece ingreso por QR común, sala de espera, control de rondas por moderación y publicación explícita de conteos agregados.

Consulta [docs/development.md](docs/development.md) para ejecutar cliente, API y PostgreSQL localmente; [docs/plan/README.md](docs/plan/README.md) contiene las fases y límites del alcance, y [docs/scope.md](docs/scope.md) el alcance completo.
